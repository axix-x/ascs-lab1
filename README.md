## 📌 Про проєкт
**Second Brain** — це спеціалізована локальна система зовнішньої пам'яті для організації, систематизації, пошуку та асоціативного зв'язування інженерних знань. 

Проєкт побудований на принципах:
- **Zero-Dependency:** працює виключно на стандартній бібліотеці Python 3 (`http.server`, `re`, `json`, `pathlib`) без сторонніх `pip`-пакетів чи `npm`.
- **Відкритий формат (No Vendor Lock-in):** усі знання зберігаються у вигляді звичайних Markdown-файлів (`.md`) із YAML frontmatter.
- **Модель PARA:** адаптована структура Тіаго Форте (`Inbox`, `Projects`, `Areas`, `Resources`, `Archives`).
- **Асоціативні зв'язки:** підтримка двонаправлених вікі-посилань (`[[Назва нотатки]]`) та автоматичний підрахунок зворотних посилань (backlinks).
- **Agent Skill:** інтеграція навички для Google Antigravity (`.agents/skills/second-brain/SKILL.md`) з правилами безпеки та забороною деструктивних дій.

## 🚀 Швидкий старт

### 1. Передумови
- Встановлений інтерпретатор **Python 3.10+** (додаткові бібліотеки встановлювати **не потрібно**).
- Будь-який сучасний веббраузер (Chrome, Edge, Firefox).

### 2. Запуск локального сервера
У терміналі виконайте:
```powershell
cd agy-lab4-second-brain
python src/server.py 8080
```

Після запуску відкрийте у браузері:
- Головний дашборд: **[http://127.0.0.1:8080](http://127.0.0.1:8080)**
- Розігрівочна форма запису (Task 4): **[http://127.0.0.1:8080/warmup](http://127.0.0.1:8080/warmup)**

## 🔒 Політика приватності та обмеження
1. **100% Offline:** застосунок працює виключно на локальному loopback-інтерфейсі (`127.0.0.1`). Жодні дані не передаються на зовнішні сервери.
2. **Відсутність платних API:** не використовуються платні хмарні моделі чи закриті вебсервіси.
3. **Безпека секретів:** репозиторій містить виключно навчальні матеріали. Паролі, токени та конфіденційні дані заборонено додавати до репозиторію.
4. **Агентна безпека:** AI-агент не має права видаляти файли або вигадувати першоджерела.
