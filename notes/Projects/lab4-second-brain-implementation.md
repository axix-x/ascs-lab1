# Лабораторна робота №4: Розробка Second Brain

## Короткий зміст
Проєкт створення персональної системи керування знаннями студента на базі платформи Google Antigravity за моделлю PARA з локальним збереженням та вебклієнтом.

## Основні твердження
- Дедлайн реалізації: поточний семестр 2026 року.
- Архітектура базується на файлах Markdown з YAML frontmatter, що забезпечує незалежність від пропрієтарних форматів (no vendor lock-in).
- Реалізується REST API на стандартній бібліотеці Python та адаптивний вебінтерфейс для пошуку й навігації за зв'язками `[[...]]`.
- Додається Agent Skill `.agents/skills/second-brain/SKILL.md` для автоматизованого сортування вхідних нотаток з каталогу Inbox.
