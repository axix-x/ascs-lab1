# Ієрархія пам'яті спеціалізованих систем

## Короткий зміст
Огляд архітектур пам'яті для високоефективних спеціалізованих обчислювачів: від регістрових файлів і Scratchpad SRAM до стекованої пам'яті HBM3 і CXL-шин.

## Основні твердження
- Спеціалізовані прискорювачі часто використовують Scratchpad Memory (SPM) замість традиційного кешу для передбачуваної латентності.
- High Bandwidth Memory (HBM) дозволяє подолати "вузьке місце фон Неймана" (Memory Wall) для задач обробки великих мовних моделей.
- Хмарні інстанси зі спеціалізованими GPU/TPU спираються на багаторівневу організацію пам'яті з підтримкою NUMA та Direct Memory Access (DMA).
